# AI_README_FIRST

新开对话，用户说出以下任一表述（或同义说法）时进入开工流程，不反问，直接执行：

- 阅读 AI 文档 / 阅读 ai 文档
- 遵守开发规范 / 遵循开发规范

## 怎么做

1. 按顺序只读以下文件（相对仓库根目录），不要通读整个 `AiHelper/`：
   1. 本文件 —— 开工总纲
   2. `AiHelper/04_SITE_OVERVIEW.md` —— 网站现状事实源
   3. `AiHelper/01_RULES.md` —— 工程红线
   4. `AiHelper/CURRENT.md` —— 跨会话未完成事项（若为"无"则无欠账）
2. 读完后用三句话汇报：网站现状一句话、欠账有无、本轮遵守的核心红线。
3. 此后本轮一切改动严格遵守 `01_RULES.md`。

## 读哪份

| 要干什么 | 打开 |
|---|---|
| 改页面、查路由 / 组件 / 样式 | `04_SITE_OVERVIEW.md` |
| 查红线、封面、游戏文件、构建 | `01_RULES.md` |
| 动布局 / 全站结构 | `02_ARCHITECTURE.md` |
| 找网站现成功能 | `03_MODULES.md` |
| 查近期改过什么 | `log.jsonl`（只 Grep，不通读） |
| 跨会话还没做完的事 | `CURRENT.md` |

## 改完写哪

| 改了什么 | 同步 |
|---|---|
| 页面结构、路由、游戏上下架 | `04_SITE_OVERVIEW.md` |
| 新增可复用组件 / 功能 | `03_MODULES.md` |
| 重要改动 | `log.jsonl` 追加一行 |
| 本轮做不完、要用户动手 | `CURRENT.md` |

`01` / `02` / `03` 未经用户许可不改。`log.jsonl` 只追加、不通读：

```json
{"d":"YYYY-MM-DD","k":"功能开发|问题修复|视觉设计|内容更新|项目整理","t":"一句话","f":["路径"]}
```
